# Basic GUI Calculator

A simple calculator with a graphical interface built with Python's Tkinter.
Enter two numbers and an operator, then press Calculate.

## Features
- Supports `+`, `-`, `*`, `/`, `%` and `**` (power)
- Handles division by zero and invalid input with clear messages

![Basic GUI Calculator](Screenshot%202025-07-29%20212407.png)

## How to run
```bash
python basic_gui_calculator.py
```
Requires Python 3.x (Tkinter comes with Python on Windows).
