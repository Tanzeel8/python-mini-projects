# Modern GUI Calculator

A colourful calculator with a graphical interface built with Python's Tkinter.
Click the buttons to build an expression and press `=` to see the result.

## Features
- Buttons for digits, `+`, `-`, `*`, `/`, decimal point, clear (`C`) and equals (`=`)
- Input is checked before it is calculated: only digits and basic operators are allowed
- Handles division by zero and invalid expressions with a clear message

## How to run
```bash
python modern_gui_calculator.py
```
Requires Python 3.x (Tkinter comes with Python on Windows).
