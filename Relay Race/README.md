# Relay Race Simulation

A simple relay race simulation. Each team has 4 runners, and every runner gets a random
running time. The team with the lowest total time wins.

## Features
- Three teams (Red, Blue, Green) with 4 runners each
- Random time for every runner (0.8 to 2.0 seconds)
- Prints each team's individual times and total time
- Announces the winner

```bash
python relay_race.py
```
