# Game Machine

A small terminal game menu with two games: Rock-Paper-Scissors and Guess the Number.

## Features
- Menu to pick a game and keep playing until you choose Exit
- Rock-Paper-Scissors against the computer
- Guess the Number (1 to 20) with 5 tries and hints (too low / too high)
- Input checks: invalid choices and non-numbers do not crash the game

```bash
python game_machine.py
```
