# Pancake Sorting Game

A terminal puzzle game. A stack of 6 pancakes is shuffled; flip the top part of the
stack until the smallest pancake is on top and the largest is at the bottom.

## How to play
- The stack is shown from top to bottom.
- Enter how many pancakes from the top you want to flip (2 to 6).
- The game ends when the stack is sorted and shows how many moves you used.

## How to run
```bash
python pancake_sorting_game.py
```
Requires Python 3.x. No extra libraries needed.

See also the [ASCII visual Pancake Sort](../ASCII%20visual%20Pancake%20Sort) project, which
sorts the stack automatically and draws each flip.
