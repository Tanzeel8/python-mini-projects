# Python Guessing Game

A word guessing game for the terminal. A hint is shown, and you have 3 attempts to
guess the secret word.

## Features
- Random word and hint on every round (5 words: giraffe, python, moon, pakistan, cricket)
- 3 attempts per round, with the correct word shown if you lose
- Not case-sensitive and ignores extra spaces
- Option to play again after each round

## How to run
```bash
python python_guessing_game.py
```
Requires Python 3.x. No extra libraries needed.
